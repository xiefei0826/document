== 复杂度分析

- *时间复杂度*：算法执行随输入规模的增长趋势，大 O 表示。
- *空间复杂度*：额外空间随输入规模的增长。
- 常见量级：`O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ) < O(n!)`。
- 计算原则：取最高阶、忽略常数与低阶项。

== 数据结构

=== 数组与链表

- 数组：连续内存，随机访问 O(1)，插入/删除 O(n)。
- 链表：节点 + 指针，插入/删除 O(1)（已知位置），随机访问 O(n)。
- 经典：反转链表、快慢指针、链表成环检测、合并有序链表、删除倒数第 N 节点。

=== 栈与队列

- 栈：后进先出，括号匹配、表达式求值、单调栈（找下一个更大/更小元素）。
- 队列：先进先出，BFS、滑动窗口（单调队列）。
- 双端队列：两端操作。

=== 哈希表

- 键值映射，O(1) 查找，两数之和、计数、去重、前缀和 + 哈希。

=== 堆（优先队列）

- 完全二叉树，大顶堆/小顶堆，TopK、合并 K 个有序链表、中位数维护。
- Java：`PriorityQueue`（默认小顶堆）。

=== 树

- 二叉树：前序/中序/后序/层序遍历（递归 + 迭代），Morris 遍历省空间。
- 二叉搜索树 BST：左小右大，中序有序；最坏退化为链表。
- 平衡树：AVL、红黑树（Java `TreeMap`）。
- 应用：树的深度、路径和、最近公共祖先 LCA、序列化与反序列化。

=== 图

- 表示：邻接矩阵、邻接表。
- 遍历：DFS、BFS（最短路径无权图）。
- 最短路径：Dijkstra（非负权）、Bellman-Ford（负权）、Floyd（多源）。
- 拓扑排序（Kahn 入度 / DFS）、最小生成树（Prim/Kruskal）、并查集判环。

=== 并查集

- 合并 + 查找，路径压缩 + 按秩合并，近 O(1)。
- 应用：连通性、判环、朋友圈/岛屿合并。

=== 字符串

- 模式匹配：KMP（`next` 数组避免回溯）。
- 前缀/后缀、字典树 Trie（前缀匹配、敏感词）。

== 核心算法

=== 排序

[cols="1,2,3,4"]
|===
| 算法 | 平均 | 最坏 | 稳定性
| 冒泡 | O(n²) | O(n²) | 稳定
| 选择 | O(n²) | O(n²) | 不稳定
| 插入 | O(n²) | O(n²) | 稳定
| 希尔 | O(n^1.3) | O(n²) | 不稳定
| 归并 | O(nlogn) | O(nlogn) | 稳定
| 快速 | O(nlogn) | O(n²) | 不稳定
| 堆 | O(nlogn) | O(nlogn) | 不稳定
| 计数/桶/基数 | O(n+k) | O(n+k) | 稳定（基数）
|===

==== 冒泡排序

从头到尾依次比较相邻两个元素，若前大于后则交换，每一轮把当前未排序区间的「最大值」冒到末尾；重复 n-1 轮完成。可加标志位，若某轮没有发生交换说明已有序，提前结束。稳定排序。

==== 选择排序

每一轮从未排序区间中「选出最小元素」，与未排序区间的首位交换，放到已排序区间的末尾；共进行 n-1 轮。因为交换可能破坏相等元素的先后顺序，不稳定。

==== 插入排序

把数组分为「已排序」与「未排序」两部分，每次取未排序区间的第一个元素，在已排序区间中从后向前找到合适位置插入（类似抓扑克牌）。当数据基本有序时接近 O(n)，适合小规模或近乎有序的数据。稳定。

==== 希尔排序

插入排序的改进：先按较大的「增量 gap」把序列分成若干组，每组内部做插入排序；然后逐步缩小增量（常见为 gap 每次减半，直到 1），最后一轮 gap=1 相当于整体插入排序。通过让元素先「大步」移动，减少后期移动次数。由于分组内交换可能跨组破坏顺序，不稳定。

==== 归并排序

采用分治思想：递归把数组从中间二分，直到每个子序列只有一个元素（天然有序），再自底向上「两两合并」成有序序列。合并时借助辅助数组，双指针比较两个子序列头部、较小者先放入结果。需要 O(n) 额外空间，稳定，适合外排序和链表。

==== 快速排序

分治 + 分区：先选一个基准值（pivot），通过一趟分区把小于基准的放左边、大于基准的放右边，基准落在最终位置；再对左右两个子区间递归执行同样操作。平均 O(nlogn)，但基准选得差（如每次取到最小/最大）会退化为 O(n²)，可优化为随机基准或三数取中。不稳定。

==== 堆排序

利用大顶堆（或小顶堆）：先把数组「建堆」，然后反复「取堆顶（当前最大值）与堆尾元素交换」，再对剩余部分向下调整维持堆结构，直到堆为空。原地排序、O(nlogn)，但不稳定。

==== 计数排序

适用于整数且取值范围有限的场景：先统计每个值出现的次数，再根据计数计算每个值在结果中的起始位置，最后按原顺序放置到输出数组，保证稳定。需要额外计数数组，空间取决于取值范围。

==== 桶排序

把数据按某种规则分配到若干「桶」中，每个桶内再单独排序（可用插入排序等），最后按桶的顺序依次合并输出。适合数据分布均匀的场景，性能依赖桶的划分。

==== 基数排序

按关键字的「位」从低位到高位（或高位到低位）依次排序：每一趟用稳定排序（如计数排序）按当前位对元素进行「分配 + 收集」，多趟后整体有序。适合整数或可拆位的关键字，稳定。

=== 二分查找

- 有序数组，O(logn)；注意边界（`left/right` 开闭区间）。
- 变体：查找第一个等于/第一个大于等于/旋转数组最小值、搜索旋转排序数组。

=== 搜索

- 深度优先 DFS：栈/递归，回溯、排列组合、岛屿、路径。
- 广度优先 BFS：队列，最短路径、层序。
- 回溯：全排列、子集、组合、N 皇后、数独；剪枝优化。

=== 动态规划（DP）

- 核心：最优子结构 + 状态定义 + 状态转移 + 边界。
- 步骤：定义 `dp[i]` 含义 → 找转移方程 → 初始化 → 遍历顺序。
- 经典：爬楼梯、背包（01/完全）、最长递增子序列、最长公共子序列、编辑距离、打家劫舍、股票买卖、零钱兑换、正则匹配。
- 优化：滚动数组压缩空间。

=== 贪心

- 局部最优 → 全局最优，需证明；跳跃游戏、分发糖果、区间调度、加油站、哈夫曼编码。

=== 位运算

- 与或非异或、移位。
- 应用：`n & (n-1)` 消最低位 1（判断 2 的幂、计算 1 的个数）、异或找唯一出现一次的数、快速乘/除 2。

=== 双指针 / 滑动窗口

- 双指针：有序数组两数之和、三数之和、接雨水、容器最多水。
- 滑动窗口：维护窗口内状态，无重复字符最长子串、长度最小子数组、找到所有字母异位词。

=== 前缀和 / 差分

- 前缀和：区间和 O(1)；`prefix[j] - prefix[i-1]`。
- 差分：区间增减 O(1)，最后前缀和还原。

== 经典题型套路

1. *两数之和*：哈希表。
2. *三数之和*：排序 + 双指针 + 去重。
3. *无重复最长子串*：滑动窗口 + Set/哈希。
4. *LRU 缓存*：`HashMap + 双向链表`（Java 可用 `LinkedHashMap`）。
5. *反转链表*：迭代/递归。
6. *环形链表*：快慢指针；入口用数学关系。
7. *二叉树的层序遍历*：队列；*深度*：递归。
8. *TopK*：小顶堆（O(nlogk)）/ 快速选择（O(n) 期望）。
9. *最长递增子序列*：DP O(n²) 或 二分 O(nlogn)。
10. *接雨水*：双指针 / 单调栈。
11. *岛屿数量*：DFS/BFS 染色。
12. *股票买卖*：状态机 DP。
13. *括号生成/有效性*：回溯 / 栈。
14. *最小路径和*：二维 DP。
15. *字符串相加/相乘*：模拟进位。

== 高频真题与参考答案

=== 1. 手写快排

- 思路：分治 + 分区，选基准，小的放左、大的放右，递归两侧。

[source,java]
----
void quickSort(int[] a, int l, int r) {
    if (l >= r) return;
    int p = partition(a, l, r);
    quickSort(a, l, p - 1);
    quickSort(a, p + 1, r);
}
int partition(int[] a, int l, int r) {
    int pivot = a[l], i = l, j = r;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;
    return i;
}
----

=== 2. 反转链表、环形链表检测

- 反转：迭代（prev/cur/next 三指针）或递归。

[source,java]
----
ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
----

- 环形检测：快慢指针，相遇则有环；找入口：相遇后一个回到头，同步走，再相遇即入口。

=== 3. 两数之和、三数之和

- 两数之和：哈希表存 `值→下标`，遍历查 `target-nums[i]`。
- 三数之和：排序 + 固定一个 + 双指针，注意去重。

=== 4. 无重复字符的最长子串

- 滑动窗口 + Set/哈希，右扩加入，重复则左缩移除，记录最大长度。

[source,java]
----
int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int l = 0, max = 0;
    for (int r = 0; r < s.length(); r++) {
        while (set.contains(s.charAt(r))) set.remove(s.charAt(l++));
        set.add(s.charAt(r));
        max = Math.max(max, r - l + 1);
    }
    return max;
}
----

=== 5. 最长回文子串

- 中心扩展：枚举每个中心（单字符/双字符），向两边扩展，O(n²)。
- 或 DP：`dp[i][j]` 表示 `s[i..j]` 是否回文。

=== 6. 二叉树的遍历（递归 + 迭代）

- 递归前序：根左右；中序：左根右；后序：左右根。
- 层序：队列逐层出队；迭代前序用栈（先压右再压左），中序用栈一路压左，后序用双栈或标记法。

=== 7. 二叉树的最近公共祖先

- 递归：左右子树分别查找，若 p、q 分布在两侧则当前节点即 LCA；若在一侧则继续该侧。

[source,java]
----
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
----

=== 8. 合并 K 个有序链表

- 小顶堆：各链表头入堆，每次弹出最小接到结果，再入该链表下一节点，O(nlogk)。

=== 9. TopK 问题

- 小顶堆：维护大小为 k 的堆，堆顶为第 k 大；O(nlogk)。
- 快速选择：基于分区，期望 O(n)。

=== 10. LRU / LFU 缓存

- LRU：`HashMap + 双向链表`，get/put 命中移到头部，超容量删尾部；Java 可用 `LinkedHashMap`（`accessOrder=true`）。

[source,java]
----
class LRUCache extends LinkedHashMap<Integer, Integer> {
    int cap;
    LRUCache(int cap) { super(cap, 0.75f, true); this.cap = cap; }
    protected boolean removeEldestEntry(Map.Entry e) { return size() > cap; }
}
----

- LFU：哈希表 + 按使用频率组织，维护 `freq → 双向链表`，淘汰最小频率最久未用。

=== 11. 爬楼梯 / 打家劫舍 / 背包问题

- 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`。
- 打家劫舍：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。
- 01 背包：`dp[j] = max(dp[j], dp[j-w] + v)`（倒序）；完全背包正序。

=== 12. 最长递增子序列 / 最长公共子序列

- LIS：DP `O(n²)`；或二分 + 贪心 `O(nlogn)`（维护递增 tails）。
- LCS：`dp[i][j] = dp[i-1][j-1]+1`（相等）否则 `max(dp[i-1][j], dp[i][j-1])`。

=== 13. 岛屿数量

- DFS/BFS 染色：遍历每个 `'1'`，计数并递归/队列淹没整个连通块，标记为已访问。

=== 14. 接雨水

- 双指针：左右指针向中移动，维护 `leftMax/rightMax`，矮的一侧决定水位，累加 `max - height[i]`。
- 或用单调栈按行计算。

=== 15. 有效的括号

- 栈：遇左括号入栈，遇右括号与栈顶匹配则弹栈，不匹配返回 false；最后栈空为 true。
