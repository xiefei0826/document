# 智能设备 + 节点验收家装平台：落地方案与资质办理指南

> 适用模式：**业主按节点验收后直接付款给装企，平台不碰工程款，只收年费/服务费**
> 适用地区：成都（可复制至全国）
> 编制时间：2026-09

---

## 第一部分：商业模式与资金合规设计

### 1.1 核心定位

**不是"资金存管平台"，而是"家装履约操作系统 + 智能设备商城"。**

| 角色 | 做什么 | 不做什么 |
|---|---|---|
| 业主 | 签施工合同、按节点直付装企、APP验收 | — |
| 装企/工长 | 施工、交付 | — |
| **平台（你）** | 展示、派单、节点标准、验收记录、纠纷协调、**卖智能设备**、**收年费** | ❌ 不代收工程款 ❌ 不设资金池 ❌ 不分账 |
| 智能设备供应商 | 供货、售后 | — |

### 1.2 资金流（合规版）

```
[业主] ──直接付款──▶ [装企/工长 对公/商户号]
   │
   └──▶ [平台智能设备商城] ──买智能设备──▶ [平台公司账户，合法]

[装企] ──交年费/服务费──▶ [平台公司账户]
```

**三条铁律：**
1. 施工款 **不经过平台账户**（对公、法人私户、平台钱包都不行）
2. 业主在 APP 点"节点验收通过"→ 弹窗提示"请向施工方指定账户支付本期款项"
3. 平台数据库只存 **验收状态、支付确认、凭证**，不存"待拨付金额/余额"

### 1.3 节点付款的产品逻辑

| 动作 | 权限归属 |
|---|---|
| 设定/修改节点比例 | 业主 + 装企协商 → 电子补充协议 → 合同锁定 |
| 提交节点完工申请 | 工长/装企（传照片、材料单） |
| 平台预审/派监理 | 平台（可打回、要求整改） |
| **最终验收确认** | **业主本人（强认证）** |
| 触发本期付款 | 业主确认后自行支付 / 平台仅记录 |
| 争议冻结 | 业主点"有异议"→ 进仲裁 |

> ⚠️ 比例在签单时锁定于《施工合同》；平台后台为"只读"，**严禁运营/工长临时改"本次转多少"**。

## 第二部分：三份基础协议

### 2.1 《平台服务协议》（对业主）

**核心条款：**

```
第X条 服务性质
本平台仅提供信息展示、施工管理工具、节点验收记录及纠纷协调服务，
不参与任何工程款的收付、托管、冻结或分账。
业主与施工方另行签订《住宅装饰装修工程施工合同》，
工程款由业主直接支付至施工方公示的收款账户。
平台不构成业主与施工方之间任何合同关系的当事人。

第X条 支付确认
业主确认"节点验收通过"后，应在合同约定的期限内，
自行向施工方指定账户支付本期款项。
平台提供的"上传支付凭证/确认已付"功能仅用于履约记录，
不代表平台代收、代付或担保任何款项。

第X条 平台责任边界
平台对施工方的施工质量、工期、报价真实性承担信息审核与规则约束责任，
但不对工程款损失承担先行赔付义务（除非另有书面质保承诺）。
```

### 2.2 《装企/工长入驻与年费协议》

**核心条款：**

```
第X条 入驻与年费
装企/工长向平台缴纳年度服务费人民币____元，
平台提供：店铺展示、业主派单、节点管理系统、评价展示、智能设备采购权。

第X条 交易独立性（关键）
入驻方与业主之间的施工合同、工程款收付、发票开具均独立于平台。
入驻方不得以平台名义收取工程款，不得使用平台账户或员工个人账户
归集业主资金。违反本条视为严重违约，平台有权立即清退并举报。

第X条 节点与验收规则
入驻方须按合同约定的节点上传完工材料，未经业主确认不得进入下一工序；
增项须经业主电子签确认，严禁私加项、催款施压。

第X条 资质与保险
入驻方应具备相应建筑业企业资质（家装业务建议持有建筑装修装饰工程专业
承包二级资质）；鼓励购买施工责任险、工人意外险。
平台有权对无资质主体限制接单。
```

### 2.3 《业主—装企施工合同（含节点付款条款）》

**核心条款：**

```
第X条 承包范围与资质
承包方持有【建筑装修装饰工程专业承包二级】资质（证书编号：____），
在资质许可范围内承揽本工程。

第X条 付款方式（节点验收付款）
本合同采用节点验收付款，共分【5】期，各期比例与金额如下：
  1) 水电隐蔽工程：合同价 30%，金额 ____元
  2) 泥木工程：合同价 35%，金额 ____元
  3) 油漆安装工程：合同价 25%，金额 ____元
  4) 设备安装与调试：合同价 5%，金额 ____元
  5) 竣工与质保：合同价 5%，金额 ____元

每一节点经业主在【平台名称】APP验收确认合格后【3】日内支付对应款项。
每期付款前，承包方应开具合法发票。

第X条 比例变更
节点比例一经约定，非经双方书面（含电子）补充协议不得变更。
变更后比例应在平台同步更新，作为付款依据。

第X条 增项
任何超出合同清单的项目须经业主书面确认后方可施工，未确认增项业主有权拒付。

第X条 质保
竣工款 5% 作为质保金，自竣工验收合格之日起满【24】个月且无遗留问题后支付。
```

## 第三部分：资质办理指南（成都）

### 3.1 要不要办资质？——要

依据《住宅室内装饰装修管理办法》第二十二条：承接住宅室内装饰装修工程的装饰装修企业，应经建设行政主管部门资质审查，取得相应建筑业企业资质证书，并在资质等级许可范围内承揽工程。多地住建部门（如佛山南海、烟台招远）明确提醒业主：施工企业应持 **建筑装修装饰工程专业承包二级或一级资质**；协会、培训机构颁发的证书一律不算。

> 对平台而言：**入驻装企必须有资质**是合规底线；若你自己公司也亲自下场施工，则你自己也必须持证。

### 3.2 资质现状（2026）

- 资质改革后，**建筑装修装饰工程专业承包资质分为一级、二级**（部分地区试点称"甲、乙"，主流仍按一、二级运行）
- **新办企业可直接申请二级**（原三级已于2021年取消）
- **二级可承接：单项合同额 2000 万元以下的装修装饰工程**（覆盖90%以上家装、中小工装需求）
- 多数地区实行 **告知承诺制**，线上申报，审批时限压缩至 15–20 个工作日

### 3.3 二级资质标准（申请条件）

| 项目 | 要求 |
|---|---|
| **企业净资产** | ≥ 200 万元 |
| **注册建造师** | 建筑工程专业注册建造师 ≥ 3 人 |
| **技术负责人** | 8年以上施工技术管理经历，具备工程序列中级以上职称 **或** 建筑工程专业注册建造师资格 |
| **职称人员** | 建筑美术设计、结构、暖通、给排水、电气等中级以上职称 ≥ 5 人 |
| **现场管理人员** | 施工员、质量员、安全员、材料员等 ≥ 10 人 |
| **技术工人** | 木工、砌筑工、镶贴工、油漆工、水电工等中级工以上 ≥ 15 人 |
| **技术负责人业绩** | 主持完成过本类别工程业绩 ≥ 2 项 |
| **企业工程业绩** | **新办二级不要求**（升级一级才要） |

### 3.4 关键难点：社保必须"本公司真实缴纳"

这是被卡得最严的一条：
- **所有人员社保由申报企业连续缴纳**（通常要求申报前 1–3 个月，各地略有差异，成都常见要求 ≥1 个月）
- 社保单位必须与申报企业一致，**外省在保、第三方代缴、个人缴纳均无效**
- 全国社保联网 + "四库一平台"穿透核查，挂靠证书极易被识别
- 技术负责人一年内不得在两家单位用于资质申报

> 💡 起步建议：直接招聘/全职聘用 3 名建造师 + 技术负责人 + 职称人员，配上真实社保，比"挂靠"稳且可持续。

### 3.5 办理流程（成都）

```
1. 工商注册 → 营业执照经营范围须含"建筑装饰装修工程"（变更工商约 3–7 天）
2. 配置人员 + 缴纳社保（提前 1–3 个月启动）
3. 准备全套材料（见下）
4. 登录"四川政务服务网 / 四川省住建厅资质管理系统"线上申报
5. 区（县）住建部门初审 → 成都市住建局实质审核（核查资产、人员、业绩）
6. 官网公示（约 5–7 个工作日）→ 无异议 → 核准
7. 办理建造师注册 → 领取电子资质证书（有效期 5 年）
```

**整体周期：材料齐全约 1–3 个月；人员配置和社保准备最耗时。**

### 3.6 材料清单

**A. 企业基础**
- 营业执照副本、最新公司章程
- 法定代表人身份证明
- 办公场所证明（租赁合同 + 产权证）
- 《建筑业企业资质申请表》（系统生成）

**B. 人员**
- 注册建造师：注册证书、身份证、社保
- 技术负责人：职称证、8年经历证明、业绩 2 项、任职文件、社保
- 中级职称人员 5 人：证书、身份证、社保
- 现场管理人员 10 人：岗位证书、社保
- 技术工人 15 人：职业培训合格/技能证书、社保
- 所有人员劳动合同

**C. 财务**
- 净资产审计报告（或验资报告 / 当期财务报表）
- 财务负责人资料 + 社保

**D. 配套**
- 告知承诺书、材料真实性承诺书（告知承诺制必备）
- 企业信用查询截图（信用中国、国家企业信用信息公示系统）

### 3.7 费用估算

| 项目 | 参考金额 |
|---|---|
| 官方费用 | 工本费数百元 |
| 建造师聘用/社保 | 约 1.5–3 万/人·年（全职聘用则并入人力成本） |
| 职称/技工人员薪酬社保 | 约 10–20 万/年（视团队规模） |
| 审计报告 | 数千元 |
| 代办（可选） | 数万元至十万元 |
| **合计（自建团队）** | **首年约 15–30 万**（主要花在"人"上） |

### 3.8 容易踩的坑

1. ❌ **经营范围没写"建筑装饰装修工程"** → 先变更工商
2. ❌ **社保断缴/代缴** → 动态核查直接撤销资质
3. ❌ **一人多岗、证书重复注册** → 驳回
4. ❌ **退休人员当技术负责人** → 不可（一般要求 ≤65 岁且不任核心岗）
5. ❌ **业绩造假** → 拉黑，影响后续招投标
6. ❌ **分公司名义签施工合同** → 多地明令不允许

### 3.9 两种起步路径对比

| 路径 | 优劣 |
|---|---|
| **A. 平台只做撮合，装企持证** | ✅ 你不用资质，启动最快 ✅ 风险低 ⚠️ 装企准入门槛高，需严审资质 |
| **B. 你自己公司亲自施工** | ✅ 交付可控、毛利高 ⚠️ 必须办二级资质 ⚠️ 重资产、现金流压力大 |

> **推荐起步走 A**：你做"智能设备 + 履约系统 + 年费"，装企持证接单；跑通后再考虑是否自己下场施工、届时再办资质。

## 第五部分：一句话总结

> **资金合规：业主验收后直接付装企，平台不碰工程款，只收年费 + 卖设备——这是启动期最轻、最稳、无支付牌照风险的模型。**
>
> **资质合规：平台撮合则装企必须持证；自己下场施工则须办「建筑装修装饰工程专业承包二级」，核心门槛是净资产 200 万 + 3 名建造师 + 真实社保，新办约 1–3 个月、首年投入 15–30 万。**
